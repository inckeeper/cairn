The following are resources for playing Cairn 2E for my players.

What Is Cairn?

Cairn is a very simple RPG system, similar to old-school D&D.
The game provides a simple rule set and relies heavily on problem solving and roleplay.
If you've played any D&D, you will be able to learn Cairn in no time!
